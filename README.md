# GhostBrowser
## Для чего
Окно-браузер, которое не видно при записи экрана (Zoom, Teams, прокторинг), не отображается в панели задач, трее и Alt+Tab/Win+Tab, курсор всегда стрелка.

---

## Требования
Только Windows 10/11, установленный в системе python (либо просто скачайте готовый [exe файл](https://github.com/dm3tr-0/GhostBrowser/releases/download/latest/default.exe))

---
## Недостатки
<p>-Не умеет открывать файлы</p>
<p>-Невозможно пройти капчу от cloudflare</p>

## Возможности
<p>-Адресная строка, кнопки назад/вперед/обновить, отображение вкладок</p>
<p>-Ползунок прозрачности (30–100%)</p>
<p>-Всегда поверх других окон</p>
<p>-Не видно при демонстрации экрана/скриншотах</p>
