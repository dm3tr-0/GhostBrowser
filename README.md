# GhostBrowser
Для чего: Окно-браузер, которое не видно при записи экрана (Zoom, Teams, прокторинг), не отображается в панели задач, трее и Alt+Tab/Win+Tab, курсор всегда стрелка.

---

Требования: Только Windows 10/11, установленный в системе python (в exe сами через pyinstaller соьберите, если надо)
Установка библиотек
```bash
pip install PyQt5 PyQtWebEngine
```
---

Возможности
    -Адресная строка (введите любой URL)
    -Ползунок прозрачности (30–100%)
    -Всегда поверх других окон
    -Не видно при демонстрации экрана/скриншотах
